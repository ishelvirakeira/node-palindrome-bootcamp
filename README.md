The Palindrome Checker allows users to input a word or phrase and validates whether it is a palindrome meaning a word or phrase that reads the same forwards and backwards. The application sends the input to a server-side JavaScript function, which reverses the string and returns it. The client-side code then compares the original input to the reversed string and displays a message indicating whether it is a palindrome on port 8002. I built both the front-end interface and the back-end logic using Node.js, the http module, and file handling with fs.
